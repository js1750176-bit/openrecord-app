Privacy Policy

Last updated: 2026-11-17

OPEN RECORD analytics is a personal tool operated by the owner of the connected YouTube channels for their own use only.

  • Data accessed: through Google OAuth and the YouTube Data API, the tool uploads videos the owner created to the owner's own channels and reads basic channel information (channel ID and title) to confirm the correct channel.
  • Storage: OAuth tokens are stored only on the owner's own computer. No data is sent to any server other than Google's APIs.
  • Sharing: no data is sold, shared, or transferred to any third party. No data is used for advertising.
  • Users: the tool has no users other than the channel owner.
  • Revoking access: access can be removed at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool also uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.
